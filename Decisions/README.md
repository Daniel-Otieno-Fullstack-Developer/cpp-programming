# C++ Decisions

Eight beginner tasks on making choices in a program with `if`, `else`, `else if`, nested `if` and `switch`.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.cpp](task1.cpp) | Pass or Fail | `if ... else` | Prints Pass or Fail for a mark |
| [task2.cpp](task2.cpp) | Even or Odd | `if + %` | Uses `%` to test for even or odd |
| [task3.cpp](task3.cpp) | Grade Calculator | `else if` | Turns a mark into a grade from A to E |
| [task4.cpp](task4.cpp) | Largest of Three | `if + &&` | Finds the biggest of three numbers |
| [task5.cpp](task5.cpp) | Leap Year | `&&  \|\|` | Applies the full leap-year rule |
| [task6.cpp](task6.cpp) | Day of the Week | `switch` | Uses `switch` to name the day |
| [task7.cpp](task7.cpp) | Menu Calculator | `switch on char` | A `switch` on the operator symbol, with a zero check |
| [task8.cpp](task8.cpp) | Bus Fare | `nested if` | Nested decisions for age and student status |

## Sample output

**Task 1: Pass or Fail**
```
Enter your mark: 67
Result: Pass
```

**Task 2: Even or Odd**
```
Enter a number: 17
17 is odd
```

## Run a task

```bash
g++ task1.cpp -o task1
./task1
```
