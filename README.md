# C++ Programming

C++ exercises and worked solutions from the ICT courses I teach at Delhi College, Eastleigh, Nairobi.

The course runs from the first data types through to classes and objects. Each topic folder has eight tasks, each with a tested solution.

## Contents

| # | Topic | What it covers | Level |
|---|---|---|---|
| 1 | [Data Types](Data%20Types) | `char`, `int`, `float`, `double`, `bool`, `string`, `void`, `sizeof` | Beginner |
| 2 | [Operators and Expressions](Operators%20and%20Expressions) | Arithmetic, `/` and `%`, casting, `++` / `--`, logical operators, precedence | Beginner |
| 3 | [Decisions](Decisions) | `if`, `else`, `else if`, nested decisions, `switch` | Beginner |
| 4 | [Loops](Loops) | `for`, `while`, `do while`, nested loops, `break` and `continue` | Beginner |
| 5 | [Functions](Functions) | Parameters, return values, prototypes, pass by reference, overloading, recursion | Beginner |
| 6 | [Arrays](Arrays) | Indexing, totals, searching, arrays and functions, 2D arrays, bubble sort | Beginner |
| 7 | [Strings](Strings) | `getline`, indexing, `find` and `substr`, character functions, conversions | Beginner |
| 8 | [Structs](Structs) | Records, arrays of structs, structs and functions, nested structs | Beginner |
| 9 | [Pointers and References](Pointers%20and%20References) | Addresses, pointers, references, pointer arithmetic, `new` and `delete` | Intermediate |
| 10 | [Classes and Objects](Classes%20and%20Objects) | Classes, encapsulation, getters and setters, constructors, inheritance | Intermediate |

## In each folder

- **README** — what each task does, with sample output.
- **task1.cpp … task8.cpp** — a worked solution for each task.

## Compiling and running

```bash
g++ task1.cpp -o task1
./task1          # on Windows: task1.exe
```
