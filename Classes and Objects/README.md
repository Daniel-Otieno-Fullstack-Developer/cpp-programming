# C++ Classes and Objects

Eight tasks introducing object-oriented programming: classes and objects, member functions, private data with getters and setters, constructors, a bank account with rules, an array of objects and a first example of inheritance.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.cpp](task1.cpp) | First Class | `class + object` | A class with a member function and two objects |
| [task2.cpp](task2.cpp) | Rectangle Class | `member functions` | Private data with calculating member functions |
| [task3.cpp](task3.cpp) | Safe Marks | `getters + setters` | A setter that validates data |
| [task4.cpp](task4.cpp) | Car Constructor | `constructors` | Default and parameterised constructors |
| [task5.cpp](task5.cpp) | Bank Account | `encapsulation` | Rules enforced inside the class |
| [task6.cpp](task6.cpp) | Visitor Counter | `state in an object` | An object that keeps its own count |
| [task7.cpp](task7.cpp) | Stock List | `array of objects` | An array of objects |
| [task8.cpp](task8.cpp) | Person and Student | `inheritance` | A derived class that reuses its base class |
