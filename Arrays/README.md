# C++ Arrays

Eight tasks on storing lists of values in arrays: reading and printing, totals and averages, highest and lowest, searching, reversing, counting, bubble sort and a 2D marks table.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.cpp](task1.cpp) | Five Marks | `declare + loop` | Reads and prints five marks |
| [task2.cpp](task2.cpp) | Total and Average | `running total` | Adds up an array of prices |
| [task3.cpp](task3.cpp) | Highest and Lowest | `max / min` | Finds the highest and lowest and where they are |
| [task4.cpp](task4.cpp) | Find a Student | `linear search` | Linear search with a -1 "not found" flag |
| [task5.cpp](task5.cpp) | Reverse Order | `backwards loop` | Prints an array backwards |
| [task6.cpp](task6.cpp) | Pass Counter | `array + function` | Passes an array to a counting function |
| [task7.cpp](task7.cpp) | Bubble Sort | `sorting` | Bubble sort, lowest to highest |
| [task8.cpp](task8.cpp) | Class Marks Table | `2D array` | Nested loops over a 2D array |
