# C++ Functions

Eight tasks on writing your own functions: parameters, return values, `bool` functions, pass by reference, overloading and a first look at recursion.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.cpp](task1.cpp) | Welcome Banner | `void + parameter` | A `void` function with a `string` parameter |
| [task2.cpp](task2.cpp) | Square and Cube | `return int` | Returns values; one function calls another |
| [task3.cpp](task3.cpp) | Area Calculator | `double functions` | Two `double` functions for areas |
| [task4.cpp](task4.cpp) | Is It Even? | `bool function` | A `bool` function used inside a loop |
| [task5.cpp](task5.cpp) | Grade Function | `char return` | Returns a `char` grade for each mark |
| [task6.cpp](task6.cpp) | Swap Two Values | `pass by reference` | Swaps two variables with references |
| [task7.cpp](task7.cpp) | Biggest Number | `overloading` | Two overloaded versions of `biggest` |
| [task8.cpp](task8.cpp) | Factorial | `loop or recursion` | A prototype, then factorials from 1 to 10 |
