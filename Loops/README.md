# C++ Loops

Eight beginner tasks on repeating code with `for`, `while` and `do while`, plus nested loops, `break` and `continue`.

## Tasks

| File | Task | Covers | What it does |
|---|---|---|---|
| [task1.cpp](task1.cpp) | Count to Ten | `for` | Counts up and down with `for` |
| [task2.cpp](task2.cpp) | Times Table | `for` | Prints a 12-line times table |
| [task3.cpp](task3.cpp) | Class Average | `while + sentinel` | Totals marks until a -1 sentinel |
| [task4.cpp](task4.cpp) | PIN Check | `do while` | Up to three PIN attempts with `do while` |
| [task5.cpp](task5.cpp) | Skip the Odd Ones | `continue` | Uses `continue` to skip odd numbers |
| [task6.cpp](task6.cpp) | Star Triangle | `nested for` | Nested loops draw a triangle |
| [task7.cpp](task7.cpp) | Guess the Number | `while + break` | Hints until the right guess, then `break` |
| [task8.cpp](task8.cpp) | Digit Sum | `while + % and /` | Splits a number into digits |
